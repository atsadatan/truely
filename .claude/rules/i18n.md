# i18n Conventions

- Default locale: `th` (Thai-first product)
- All user-facing text must use `useTranslations()` — no hardcoded Thai/English strings in components
- Translation keys: nested by feature namespace (`landing.hero`, `auth.login`, `dashboard.strengths`)
- Both `th.json` and `en.json` must stay in sync — add keys to both when adding new text
- Use `{variable}` syntax for interpolation: `"progress": "คำถามที่ {current} จาก ~{total}"`
- Navigation: always import from `@/i18n/navigation`, never from `next/link` or `next/navigation`
